## 三段分离（函数名不要变，只换里面的字段）

1. `parse_records(text)` — 只解析：原始文本 → 类型化记录。不算总和、不打印。
2. `calculate_totals(records)` — 只计算：记录 → 聚合结果。不解析、不格式化、不在这里四舍五入到分。
3. `format_output(totals)` — 只输出：排序 + 金额 quantize 到分都在这里，不碰数学。

`run_pipeline(text)` 是唯一把三段串起来的地方。

## 每段写完立刻自测（不要等全部写完）

**Parse 段**
- [ ] 空输入 → 返回空，不崩
- [ ] 空行跳过
- [ ] 重复记录（同 txn_id）：第一条为准，后面的跳过
- [ ] 坏行报错并带行号

**Calc 段**
- [ ] 金额用 `Decimal("字符串")`，绝不用 float（0.10 + 0.20 必须精确等于 0.30）
- [ ] 重复已在 parse 段去掉，这里不会重复计数
- [ ] 空列表 → 空结果

**Output 段**
- [ ] 输出顺序固定（按 key 排序）
- [ ] 每个金额都 quantize 到 0.01，舍入方式写明（ROUND_HALF_UP）
- [ ] 空结果输出明确的一行（如 `(no transactions)`），不留空白、不崩
